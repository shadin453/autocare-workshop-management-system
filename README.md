# Autocare Workshop Management System

## Project Overview

The Autocare Workshop Management System is a C programming project developed to support the daily operations of an automobile workshop. The system is designed to manage customer information, vehicle servicing, appointments, billing, inventory, and service records.

It provides a structured way to store and manage workshop data, helping to reduce manual work and improve the efficiency of workshop operations.

## Objectives

- To manage customer and vehicle information.
- To record and manage service appointments.
- To maintain service and billing records.
- To manage workshop inventory and spare parts.
- To organise workshop data using C programming.
- To provide a simple and efficient workshop management system.

## Main Features

### Customer Management
- Add and manage customer information.
- Store customer records for future reference.

### Vehicle Management
- Manage vehicle-related information.
- Connect vehicle details with customer records.

### Appointment Management
- Record and manage service appointments.
- Store appointment information in text files.

### Service Management
- Maintain service records.
- Manage workshop service-related information.

### Billing Management
- Store and manage billing records.
- Organise payment-related information.

### Inventory Management
- Manage spare parts and inventory records.
- Track parts usage and availability.

### Technician Management
- Manage technician-related information.
- Support workshop service operations.

## Technologies Used

- **Programming Language:** C
- **Data Storage:** Text Files
- **Development Environment:** C Programming IDE
- **Version Control:** GitHub
